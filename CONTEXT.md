# Контекст: Календарь бронирований

Публичная запись гостей на события по слотам без регистрации. Один контекст
на всё приложение (посетитель и администратор оперируют одними и теми же
понятиями); см. [REQUIREMENTS.md](./REQUIREMENTS.md) и
[docs/user-scenarios.md](./docs/user-scenarios.md).

## Language

**Посетитель**:
Анонимный человек в публичной части приложения; не регистрируется и не
аутентифицируется.
_Avoid_: пользователь, клиент

**Гость**:
Посетитель, оставивший свои данные (имя, email, телефон); идентифицируется
по email.
_Avoid_: клиент, зарегистрированный пользователь

**Тип события**:
Услуга, на которую записывается гость; имеет длительность одного слота
(15 или 30 минут) и цвет для отображения в календаре.
_Avoid_: услуга, категория

**Слот**:
Единичный интервал времени внутри дня, который можно забронировать;
принадлежит ровно одному типу события.

**Статус слота**:
Состояние слота в сетке для посетителя: `free` (свободен), `pending`
(занят неподтверждённой бронью), `confirmed` (занят подтверждённой бронью).
_Avoid_: занятость

**Бронь**:
Запись гостя на один слот; создаётся в статусе `pending` и занимает слот
сразу.
_Avoid_: запись, резерв (в значении брони), заказ

**Длительная бронь**:
Бронь на несколько последовательных слотов одного типа события, оформленная
одной операцией.
_Avoid_: групповая бронь (это группа броней, а не один объект для гостя)

**Группа броней**:
Несколько броней одной операции, объединённые общим идентификатором
`booking_group_id`.
_Avoid_: бронь-контейнер

**Горизонт бронирования**:
Окно дат, доступных для бронирования: со следующего дня после текущего
и на 14 дней вперёд.
_Avoid_: период записи

**Период доступности**:
Регулярный рабочий интервал (день недели, время начала и окончания), внутри
которого возможно бронирование.
_Avoid_: рабочие часы (в значении правила)

**Исключение**:
Конкретная дата с полным или частичным закрытием, перекрывающая периоды
доступности.
_Avoid_: выходной (исключение может быть и частичным)

**Лимит дня**:
Максимум суммарной продолжительности броней одного гостя за один
календарный день — 2 часа; отменённые (`cancelled`) брони не учитываются.
_Avoid_: квота, месячный лимит

**Релиз**:
Именованный срез состояния всего приложения целиком — публичной части,
админ-панели и API-контракта вместе; версионируется по SemVer сквозным
счётом по всему репозиторию. Релиз не предполагает развертывания.
_Avoid_: деплой, публикация пакета

**Версия API**:
Версия контракта в путях запросов (`/api/v1`); меняется независимо от
номера релиза.
_Avoid_: версия релиза, версия приложения
